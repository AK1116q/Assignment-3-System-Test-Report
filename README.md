# Assignment 3 System Tests

This repository collects system tests for the OpenCart demo store.

The current Python/Selenium tests for Product Comparison, Category Browsing,
and Contact Us are in `tests/T004-T006-selenium`. That folder has run
instructions and report evidence. The earlier JavaScript/Playwright version
remains in `tests/T004-T006` for reference. Other group members can add their
own tests in separate folders.
